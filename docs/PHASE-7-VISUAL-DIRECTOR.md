# FASE 7 — Visual Director

Phase 7 replaces title-level/generic visual prompting with a scene-specific visual planning layer.

## Flow

```text
Script scene
  -> VisualDirectorV7
  -> VisualBrief
  -> anti-generic quality score
  -> accepted prompt
  -> image provider or local explanatory renderer
  -> scene asset
```

Each brief records the scene subject, context, viewer takeaway, visual type, shot, composition, concrete details, relevant evidence hints, avoid-list, global Lumen Atlas identity, per-video instructions, and quality metrics.

## Visual types

The deterministic director routes scenes to one of these starting modes:

- `archival_timeline`
- `comparison`
- `location_map`
- `experiment_diagram`
- `technical_diagram`
- `data_explainer`
- `documentary_establishing`
- `documentary_explainer`

Phase 8 will add licensed/public-source asset routing. Phase 7 does not claim that a generated diagram is a real archival photograph or a verified source asset.

## Quality gate

The current deterministic quality metrics are:

- scene relevance
- specificity
- evidence alignment
- composition
- style consistency
- generic-AI risk

A prompt must reach specificity >= 70 and generic-AI risk <= 50. If the first brief is too generic, the director enriches it using concrete terms already present in the scene/topic and falls back to an explanatory-diagram mode rather than inventing new factual detail.

These scores are prompt-quality heuristics, not scientific-truth probabilities. Factual truth remains governed by the Phase 5 Evidence Desk.

## Evidence boundary

Research source titles/publishers can be carried into a VisualBrief as context when they overlap the scene. Phase 7 does not fetch or license visual assets from those sources; that belongs to Phase 8.

## Local fallback

When no image provider is usable (including Gemini Images quota=0), the local renderer creates a scene-specific explanatory PNG. It parses the VisualBrief fields and chooses a different diagram grammar for comparisons, timelines, maps, experiments, technical systems, data explanations, and documentary scenes.

The local render is intentionally labeled internally as a local explanatory render. It is not represented as documentary evidence.

## Per-video instructions

Phase 6 `Instructions` survive Phase 7. They are stored in the brief and included in the final provider prompt under `VIDEO DIRECTION`. They remain preferences and cannot override evidence, safety, media rights, platform, approval, or publishing gates.

## Legacy jobs

Existing jobs are upgraded with v7 VisualBriefs and prompts. Completed visual assets are not automatically regenerated by default because that could consume provider credits unexpectedly.

To explicitly refresh already-completed legacy visuals during Resume:

```env
VISUAL_DIRECTOR_REFRESH_LEGACY_VISUALS=true
```

Default:

```env
VISUAL_DIRECTOR_REFRESH_LEGACY_VISUALS=false
```

New jobs always use Visual Director v7 before their first visual provider call.

## Regression test

```powershell
npm run test:visual-director
```

The regression suite uses deterministic fixtures and does not call paid image APIs.
